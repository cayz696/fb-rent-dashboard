# Аудит проєкту FB Rent — 09.10.2026

## ✅ Зроблено й працює (перевірено)

**Основа:** Postgres, API (FastAPI), Web (Next.js, тема Obsidian), bridge (AdsPower), docker-compose-каркас.

**Доступ:** логін + 2FA (TOTP), ролі admin/operator/viewer, керування користувачами, rate-limit.

**Акаунти:** повна модель, статус-машина (purchased→…→issued, + **sold**, returned, off), журнал подій, CRUD, фільтри (етап, клієнт, постачальник, партія, **група AdsPower**, сигнали), пошук, масовий перехід, пагінація.

**Дашборд:** KPI, воронка етапів + Off-пул, реєстр (вкладки), панель заявок, панель сигналів.

**Заявки (без Telegram):** створення вручну, автопідбір найстаріших `ready`, Змінити/Підібрати/Апрув/Відхилити.

**AdsPower (реально):** Local API, завід акаунта з cookies/2FA/проксі, синхронізація **606 профілів → 616 акаунтів** з групами, авто-перенос у групу при зміні етапу (ready→Готовий, sold→Продано…).

**Імпорт замовлення:** order.txt → AdsPower (файл, байт-у-байт як ChatGPT) + автозавід через bridge + проксі.

**Фінанси:** % від спенду по клієнтах, оплати, баланс, маржа; **виручка з продажів**.

**FBM-pay (реально):** розділ «Картки» — 217 карток, спенд $119k, статуси, **3DS-коди наживо**; §4 (лише маски).

**Сповіщення:** дзвіночок, агрегація (заявки/сигнали/помилки bridge).

**Тести:** API 93, bridge 11. BM ID клієнта (поле).

## 🔧 Частково / потребує наступного кроку
- **Зв'язок картка↔акаунт** — по `card_last4`; зараз 0 (last4 не заповнено). Треба: ввід last4 на етапі «Карта» → спенд/3DS картки в картці акаунта; (опц.) автозаповнення last4 з нотаток AdsPower.
- **Кінги** як керований пул — група видима; збір статки чекає аналітичний API.
- **Clover** — код є, але не використовується (замінять FBM + аналітичний API). Прибрати/перепрофілювати.

## 📋 Лишилось
1. **Аналітичний API** (обіцяли) → джерело спенду, прив'язка до акаунтів, оживлення Кінгів/фінансів.
2. **FBM як джерело спенду** (по last4) + **сигнал «ліміт/баланс картки вичерпується»**.
3. **«Розшарити доступ»** (BM-партнер): Фаза 1 (ручна дія + фіксація) → Фаза 2 (bridge Graph API через проксі акаунта). Деталі — spec-share-access.md.
4. **Telegram** (userbot + бот адміна) — за домовленістю в останню чергу.
5. **ШІ-агент** (MVP-5 ТЗ) — потрібен ключ LLM.
6. **Чеклист підготовки акаунта** (аватар/обкладинка/телефон) — «людина робить, система фіксує» (опц.).
7. **Деплой:** Docker-білди, VPS, Caddy (HTTPS), бекапи pg_dump — усе поки лише локально.

## ⚠️ Технічний борг / нотатки
- Сервіси (bridge, web) запущені як `nohup` — помирають за дні простою. На проді (docker/systemd/Caddy) зникне.
- Демо-акаунти (FB-0001…FB-0014) змішані з реальними 606 — можна почистити.
- Реальні дії над AdsPower тестуємо лише на FB-0014 (домовленість).
